# 新旧朗2 旧版ファイル削除ツール

GitHub の `blob` ページはファイルの表示ページです。ユーザーには次のダウンロードリンクを案内してください。

- [ZIP をダウンロード](https://vramwiz.github.io/Syncroh2-site/files/Syncroh2_LegacyCleanup.zip)
- [EXE を直接ダウンロード](https://vramwiz.github.io/Syncroh2-site/files/Syncroh2_LegacyCleanup.exe)

実行前に [削除対象と手順](https://vramwiz.github.io/Syncroh2-site/legacy-cleanup.html) を確認してください。

このフォルダーにあるファイルを GitHub から直接取得する場合は、ZIP は
[Raw ZIP](https://github.com/vramwiz/Syncroh2-site/raw/refs/heads/main/files/Syncroh2_LegacyCleanup.zip)、
EXE は [Raw EXE](https://github.com/vramwiz/Syncroh2-site/raw/refs/heads/main/files/Syncroh2_LegacyCleanup.exe) を使用します。
